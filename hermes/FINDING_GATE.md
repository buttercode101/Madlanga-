# Finding Gate

A proposed conclusion may pass only when:
- the issue is explicitly identified;
- the complete relevant evidence set has been retrieved;
- source quality is adequate for the claim;
- contrary evidence and contradictions were checked;
- uncertainty is explicit;
- the output is clearly labelled as analysis unless it is quoting an actual official finding;
- no allegation is represented as fact.

Gate states: PASS, CONDITIONAL, BLOCKED.
