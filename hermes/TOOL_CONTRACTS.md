# Tool Contracts

Hermes agents are read-first and evidence-bound.

They may:
- search registered sources;
- retrieve source snapshots;
- query claims, hearings and relationships;
- compare source versions;
- propose evidence gaps.

They may not:
- edit immutable source snapshots;
- invent evidence;
- write official findings;
- bypass provenance;
- use private user context as factual evidence;
- turn model confidence into proof.

Ingestion is a separate controlled operation with hashing and audit logging.
